# SEO Content Analyzer 🔍

A Python tool that analyzes articles and reports SEO metrics like word count, sentence structure, and keyword density.

## 📋 What It Does

- Counts total words in an article
- Counts total sentences  
- Calculates average words per sentence
- Checks for important keywords
- Generates an SEO readiness score

## 🚀 How to Use

1. Make sure you have Python installed (Python 3.6+)
2. Place your article in `article.txt`
3. Run the analyzer:
   ```bash
   python seo_analyzer.py
